# Storm watch

Show weather prediction as either graphs or warnings for next hours

This needs connection to GadgetBridge, but uses direct http access to
open-meteo.com, so no further setup is neccessary. (Thanks for great service!)

Use "mylocation" application to set up location. Be aware that your
location will be transmitted to open-meteo.com.
