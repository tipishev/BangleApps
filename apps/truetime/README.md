# True Time

Clock showing time with uncertainity.

This clock tracks time from last synchronization, and displays time
with uncertainity. When given digit of time is not certain, it
randomizes and blurs it.

You can set current clock from GPS by pressing bottom right part of
screen; note that full gps fix is not required for this, so it works
within seconds even indoors.
